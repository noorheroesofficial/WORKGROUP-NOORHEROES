# NoorHeroes V2 — Avatar Library

Created 22 October 2026 using Canva image generation and the supplied screenshot references.

[Open the complete Figma library](https://www.figma.com/design/MR9935oQZACMjndzGIUgq5/NoorHeroes-APP?node-id=1842-3309).

## Delivery

Twenty original, separate 1264 × 1264 PNG images are in `assets/`, named `avatar_01.png` through `avatar_20.png`. They contain ten boy and ten girl characters. Each has a clean warm ivory background and a centered head-and-shoulders composition. These are opaque square images; use a circular mask in the consuming app when needed.

The Canva Download interface labeled its downloads with a .jpg filename, but file decoding confirmed that every download contained PNG bytes. Only filenames were normalized to .png. The delivered bytes match the original downloads without resizing or recompression.

The new Figma frame is on the existing 📱 NH Mobile page, beside the supplied empty Frame 3 (1431:11603). Frame 3 and its existing neighboring frames retain their inspected position and dimensions. The library is a separate 976 × 1084 Auto Layout frame, with five columns and four rows. Each original is retained as an image fill in an individually selectable, labeled 120 × 120 preview node.

Figma preview nodes have rounded corners; the PNG files in this package retain the full square image. Use these original files when full square corners are required. Preview nodes have 1264 px PNG export settings.

## Reference analysis and creative direction

All 22 supplied screenshots were inspected. The dominant group uses soft 3D toy-like children: oversized rounded heads, large glossy eyes, rosy cheeks, warm smiles, modeled fabric and modest clothing. Hijabs, kufis, floral trims, glasses and pastel accents give individual characters identity. Several screenshots repeat the same reference character or closely related poses. Four screenshots show a separate flat 2D comic treatment; that minority style was excluded to keep this collection coherent.

Representative references uploaded to Canva were 110010 (pink-hijab girl), 110023 (white-kufi boy), 110933 (floral-hijab girl) and 111041 (girl with glasses). Every generation used those four references plus a distinct character description. The remaining supplied references informed the visual analysis.

Reference filenames, all from 22 October 2026: 110010, 110023, 110044, 110054, 110059, 110106, 110610, 110619, 110627, 110715, 110720, 110731, 110740, 110933, 110938, 110945, 110950, 111029, 111034, 111041, 111048 and 111055.

The collection uses original character variations rather than copying the source characters. Skin tones, eye colors, hair, headwear, clothing, embroidery and glasses vary while rendering style, framing and lighting remain consistent. Head-and-shoulders composition keeps faces legible in small profile crops. No generated religious text or calligraphy was requested.

## Review and verification

All 20 images were reviewed individually and together for clear faces, coherent style, headwear visibility, duplicate characters, image sharpness and unwanted text. The review accepted all 20 outputs. The full-resolution contact sheet is in `evidence/contact-sheet.png`; the final Figma render is `evidence/figma-avatar-library.png`.

Automated evidence in `evidence/asset-audit.json` confirms 20 valid PNGs, 1264 × 1264 dimensions for every image, 20 distinct file hashes and preservation of original downloaded bytes. `evidence/figma-audit.json` confirms 20 unique Figma image fills, original source dimensions, all 20 labels, no node overflow, and matching inspected geometry for the pre-existing page frames.

These are raster illustrations. Individual character features are not separate editable vector shapes. The Figma image nodes, labels, cards and grid remain separately editable.
